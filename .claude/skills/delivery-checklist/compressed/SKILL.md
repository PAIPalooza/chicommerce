# Delivery Checklist & Mini-Prompts

## Default Loop
**Plan → Implement → Artifacts → PR → Verify → Deliver**

Workflow:
1. Plan (checklist)
2. Artifacts (logs, screenshots)
3. Findings
4. Code Diffs
5. Tests
6. PR Description
7. Next Steps

## Acceptance Checklist
* [ ] Story type/estimate set; branch convention
* [ ] Red→Green→Refactor commits
* [ ] Tests passing locally/CI
* [ ] Security/a11y/responsive checked
* [ ] PR description w/ evidence
* [ ] Staging deploy verified

## Reusable Mini-Prompts
* **Classify:** Story type, estimate, rationale
* **TDD:** Minimal failing tests, implementation
* **Refactor:** Complexity reduction
* **PR Composer:** Problem/Solution/Tests/Risks
